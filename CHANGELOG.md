## [1.0.0] – 2025-08-23

### Added

- **Parallax background** with responsive resizing
- **Animated ghost snail** with curled state and upward movement
- **Butterfly swarm** (initial, overlapping version)
- **License** to encourage artwork reuse (with credit)

### Changed

- Refactored sprite system into a dedicated class
- Refactored project structure (added components)
- Visual polish: layer fixes, removed white-line bug
- Performance and **cross-browser speed improvements**
- Documentation updates and UI text refinements

### Removed

- Development files (`.vscode` folder, old configs)
- Temporary deployment configs (Vercel.json)
