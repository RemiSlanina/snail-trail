# 🐌 Snail Trail

A little **ghost snail** moving slowly through a **parallax landscape**.  
Written in **JavaScript** + **SVG** as a demo and personal recovery project.

---

## ✨ Project Status

> ⚠️ **Work in Progress (WIP)**  
> I am still adding new features, bugfixes, and optimizations.

This started as a small animation experiment while I was recovering, and has been growing step by step.

---

## 🎨 Artwork & Assets

All artwork was drawn by me (snail, butterflies, parallax background).  
The animations use simple sprite sheets:

- 🐌 **Snail sprite** → `215 × 130px`
  - Sprite sheet: `9 × 4` frames → `1935 × 520px`
- 🦋 **Butterfly sprite** → `100 × 80px`
  - Sprite sheet: `7 × 3` variations → `700 × 240px`
- 🌄 **Parallax background** → `700 × 2400px`

_Note:_ Both `.webp` and `.svg` versions are available (similar file sizes).
